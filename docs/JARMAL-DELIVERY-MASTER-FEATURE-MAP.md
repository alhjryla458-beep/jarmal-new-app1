# جَرْمَل للتوصيل — خريطة الميزات الرئيسية

> هذا المستند يخص **جَرْمَل للتوصيل فقط**. مشروع جَرْمَل لقطع غيار السيارات مشروع مستقل ولن تُضاف ميزاته إلى هذا التطبيق.

## الهوية
- تطبيق توصيل احتياجات يومية داخل اليمن.
- العملاء: البقالات، المطاعم، المقاهي، الصيدليات، الملابس، الإلكترونيات، الحلويات وغيرها.
- الأدوار: العميل، التاجر/صاحب المتجر، المندوب، الإدارة.
- تجربة عربية سهلة ومناسبة للإنترنت الضعيف.

## الموجود ويجب الحفاظ عليه
- الطلبات ودورة حياة الطلب.
- الدفع النقدي والإلكتروني وإيصالات الدفع.
- المحافظ المالية للتاجر والمندوب.
- تسويات الكاش للمندوب.
- أجور المندوبين.
- اعتماد المتاجر واعتماد المندوبين.
- المخزون وأعضاء فريق المتجر.
- موقع العميل على الخريطة.
- الإلغاء الآمن للطلب.
- الولاء/النقاط.
- المفضلة وإعادة الطلب.
- الخدمات الرقمية/الدفع حسب البنية الحالية.
- لوحة إدارة مستقلة عن تطبيق العميل.

## الميزات التالية ذات الأولوية
1. رفيق جَرْمَل المتحرك: مساعد سياقي للعميل والتاجر والمندوب، يعمل محليًا أولًا ولا يفرض خدمة AI مدفوعة.
2. مركز الإشعارات الحقيقي.
3. محادثة مرتبطة بالطلب بين العميل والمندوب، مع دعم/إدارة عند الحاجة.
4. العناوين والأماكن المحفوظة: المنزل، العمل، المتجر، وغيرها، مع وصف + دبوس خريطة + معلم.
5. تعديل الطلب قبل بدء الشحن وفق سياسة آمنة.
6. المستلم مختلف عن صاحب الحساب.
7. طلب متعدد المتاجر مع مجموعات تنفيذ منفصلة لكل متجر.
8. إعادة محاولة التوصيل عند تعذر التسليم.
9. الإرجاع والاستبدال والاسترداد بسياسة واضحة.
10. القسائم والعروض.
11. تذاكر الدعم وخدمة العملاء.
12. وضع الإنترنت الضعيف وحفظ المسودة محليًا.
13. تحسين البحث والتصفية وساعات العمل ومناطق التوصيل.
14. تقارير تشغيلية ومالية أعمق للإدارة.
15. JARMAL APP STUDIO لإدارة المحتوى والتصميم والميزات القابلة للتكوين.
16. نظام رفيق/مساعد خاص بالمندوب والتاجر داخل واجهتيهما.

## حدود الأمان
- لا يملك محرر التصميم صلاحية تغيير RLS أو منطق المال أو صلاحيات المستخدمين.
- أي عملية مالية أو حساسة تبقى خلف RPC آمن وصلاحيات خادمية.
- لا نضيف بيانات اختبار وهمية إلى الإنتاج.
- كل تغيير: فحص → تعديل صغير → تحقق → نشر/فحص.
